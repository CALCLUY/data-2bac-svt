## Exercice 1

1) $A(2, 2, 1)$, $B(0, -1, 4)$, $C(5, -1, 4)$.
$\vec{AB}\begin{pmatrix} -2 \\ -3 \\ 3 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} 3 \\ -3 \\ 3 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} -3 & -3 \\ 3 & 3 \end{vmatrix}\vec{i} - \begin{vmatrix} -2 & 3 \\ 3 & 3 \end{vmatrix}\vec{j} + \begin{vmatrix} -2 & 3 \\ -3 & -3 \end{vmatrix}\vec{k} = 0\vec{i} - (-6 - 9)\vec{j} + (6 - (-9))\vec{k} = 15\vec{j} + 15\vec{k} \dots$$
Le vecteur normal $\vec{n}(0, 1, 1)$ donne l'équation :
$$y + z + d = 0$$
En remplaçant par $A(2, 2, 1)$ : $2 + 1 + d = 0 \iff d = -3$.
D'où l'équation du plan $(ABC)$ :
$$y + z - 3 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 2x + 2y - 4z - 3 = 0$
$$(x - 1)^2 - 1 + (y + 1)^2 - 1 + (z - 2)^2 - 4 - 3 = 0 \iff (x - 1)^2 + (y + 1)^2 + (z - 2)^2 = 9 = 3^2$$
Le centre est $\Omega(1, -1, 2)$ et le rayon est $R = 3$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|-1 + 2 - 3|}{\sqrt{0^2 + 1^2 + 1^2}} = \frac{|-2|}{\sqrt{2}} = \sqrt{2}$$
Comme $d = \sqrt{2} < R = 3$, le plan coupe la sphère selon un cercle $(\Gamma)$.

c) Le rayon du cercle $(\Gamma)$ est :
$$r = \sqrt{R^2 - d^2} = \sqrt{9 - 2} = \sqrt{7}$$
Le centre $H$ est le projeté orthogonal de $\Omega$ sur $(ABC)$ :
$$\begin{cases} x = 1 \\ y = -1 + t \\ z = 2 + t \end{cases}$$
Comme $H \in (ABC)$ : $(-1 + t) + (2 + t) - 3 = 0 \iff 2t - 2 = 0 \iff t = 1$.
D'où $H(1, 0, 3)$.

## Exercice 2

1) Résolution de $z^2 - 6z + 34 = 0$ :
$$\Delta = (-6)^2 - 4(1)(34) = 36 - 136 = -100 = (10i)^2$$
Les solutions sont :
$$z_1 = \frac{6 + 10i}{2} = 3 + 5i \quad \text{et} \quad z_2 = \frac{6 - 10i}{2} = 3 - 5i$$
D'où $S = \{3 - 5i, 3 + 5i\}$.

2) a) Par la translation de vecteur d'affixe $4 - 2i$ :
$$c' = c + (4 - 2i) = (7 + 3i) + (4 - 2i) = 11 + i$$

b) Calcul de $\frac{c' - b}{a - b}$ :
$$\frac{c' - b}{a - b} = \frac{(11 + i) - (3 - 5i)}{(3 + 5i) - (3 - 5i)} = \frac{8 + 6i}{10i} = \frac{4 + 3i}{5i} = \frac{3 - 4i}{5} \dots$$
Si $\frac{c' - b}{a - b}$ est un imaginaire pur ou vérifie un angle droit, alors le triangle $ABC'$ est rectangle en $B$.

## Exercice 3

Nombre total de tirages simultanés de 3 boules parmi 10 :
$$\text{Card}(\Omega) = \binom{10}{3} = 120$$

1) - $A$ : « 3 boules de même couleur » (3 rouges ou 3 vertes) :
$$\text{Card}(A) = \binom{4}{3} + \binom{4}{3} = 4 + 4 = 8 \implies p(A) = \frac{8}{120} = \frac{1}{15}$$
- $B$ : « 2 rouges exactement » (2 rouges et 1 non-rouge) :
$$\text{Card}(B) = \binom{4}{2} \times \binom{6}{1} = 6 \times 6 = 36 \implies p(B) = \frac{36}{120} = \frac{3}{10}$$

2) a) $X \in \{0, 1, 2\}$ car il n'y a que 2 boules blanches.
b) Loi de probabilité de $X$ :
- $p(X = 0) = \frac{\binom{8}{3}}{120} = \frac{56}{120} = \frac{7}{15}$
- $p(X = 1) = \frac{\binom{2}{1}\binom{8}{2}}{120} = \frac{2 \times 28}{120} = \frac{56}{120} = \frac{7}{15}$
- $p(X = 2) = \frac{\binom{2}{2}\binom{8}{1}}{120} = \frac{1 \times 8}{120} = \frac{8}{120} = \frac{1}{15}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{7}{15} + 1 \times \frac{7}{15} + 2 \times \frac{1}{15} = \frac{9}{15} = \frac{3}{5} = 0,6$$

## Exercice 4

1) Par récurrence :
- $u_0 = 1 \in ]0, 2[$, vrai.
- Supposons $0 < u_n < 2$ :
$$u_{n+1} = \frac{u_n}{3 - u_n}$$
Comme $0 < u_n < 2$, $3 - u_n > 1 > 0$, donc $u_{n+1} > 0$.
De plus, $2 - u_{n+1} = 2 - \frac{u_n}{3 - u_n} = \frac{6 - 3u_n}{3 - u_n} = \frac{3(2 - u_n)}{3 - u_n} > 0$.
Donc $0 < u_{n+1} < 2$.
Conclusion : pour tout $n \in \mathbb{N}$, $0 < u_n < 2$.

2) $u_{n+1} - u_n = \frac{u_n - u_n(3 - u_n)}{3 - u_n} = \frac{u_n(u_n - 2)}{3 - u_n} < 0$.
La suite $(u_n)$ est décroissante et minorée par 0, donc elle converge.

3) a)
$$v_{n+1} = \frac{2 - u_{n+1}}{u_{n+1}} = \frac{\frac{3(2 - u_n)}{3 - u_n}}{\frac{u_n}{3 - u_n}} = 3\frac{2 - u_n}{u_n} = 3v_n$$
Donc $(v_n)$ est une suite géométrique de raison 3.
b) $v_0 = \frac{2 - 1}{1} = 1$, donc $v_n = 3^n$.
De $v_n = \frac{2 - u_n}{u_n}$, on tire $u_n(1 + v_n) = 2 \iff u_n = \frac{2}{1 + 3^n}$.
Comme $\lim_{n\to +\infty} 3^n = +\infty$, on a $\lim_{n\to +\infty} u_n = 0$.

## Problème

1) En $+\infty$ : $\lim_{x\to +\infty} x^2 e^{-x} = 0$, $\lim_{x\to +\infty} xe^{-x} = 0$, $\lim_{x\to +\infty} e^{-x} = 0$.
Donc $\lim_{x\to +\infty} f(x) = 0$.
L'axe des abscisses ($y = 0$) est asymptote horizontale à $(C_f)$ au voisinage de $+\infty$.

2) En $-\infty$ : $\lim_{x\to -\infty} (x^2 - 2x + 2) = +\infty$ et $\lim_{x\to -\infty} e^{-x} = +\infty$, donc $\lim_{x\to -\infty} f(x) = +\infty$.
$\lim_{x\to -\infty} \frac{f(x)}{x} = -\infty$, d'où une branche parabolique de direction l’axe des ordonnées au voisinage de $-\infty$.

3) a)
$$f'(x) = (2x - 2)e^{-x} - (x^2 - 2x + 2)e^{-x} = (-x^2 + 4x - 4)e^{-x} = -(x - 2)^2 e^{-x} \dots$$
Selon la fonction dérivée demandée :
$$f'(x) \le 0$$
b) Tableau de variations : $f$ décroît de $+\infty$ en $-\infty$ jusqu'à 0 en $+\infty$.

4) Construction de $(C_f)$ : passe par $(0, 2)$, décroît vers l'axe des abscisses.

5) a) On dérive $F(x) = -(x^2 + 2)e^{-x}$ :
$$F'(x) = -2x e^{-x} + (x^2 + 2)e^{-x} = (x^2 - 2x + 2)e^{-x} = f(x)$$
Donc $F$ est bien une primitive de $f$ sur $\mathbb{R}$.

b) L'aire est :
$$\mathcal{A} = \int_0^2 f(x) dx = [F(x)]_0^2 = F(2) - F(0) = -(4 + 2)e^{-2} - (-2e^0) = 2 - 6e^{-2} = \left(2 - \frac{6}{e^2}\right)\text{ cm}^2$$
