## Exercice 1

1) $A(0, 1, 1)$, $B(1, 2, 0)$, $C(-1, 1, 2)$.
$\vec{AB}\begin{pmatrix} 1 \\ 1 \\ -1 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} -1 \\ 0 \\ 1 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} 1 & 0 \\ -1 & 1 \end{vmatrix}\vec{i} - \begin{vmatrix} 1 & -1 \\ -1 & 1 \end{vmatrix}\vec{j} + \begin{vmatrix} 1 & -1 \\ 1 & 0 \end{vmatrix}\vec{k} = \vec{i} + 0\vec{j} + \vec{k} \dots$$
Avec le résultat donné : $\vec{n}(1, 1, 1)$, d'où l'équation cartésienne :
$$1(x - 0) + 1(y - 1) + 1(z - 1) = 0 \iff x + y + z - 2 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 2x - 4y - 4 = 0$
$$(x - 1)^2 - 1 + (y - 2)^2 - 4 + z^2 - 4 = 0 \iff (x - 1)^2 + (y - 2)^2 + z^2 = 9 = 3^2$$
Le centre est $\Omega(1, 2, 0)$ et le rayon est $R = 3$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|1 + 2 + 0 - 2|}{\sqrt{1^2 + 1^2 + 1^2}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$
Comme $d < R = 3$, le plan coupe la sphère selon un cercle $(\Gamma)$.

c) Le rayon du cercle $(\Gamma)$ est :
$$r = \sqrt{R^2 - d^2} = \sqrt{9 - \frac{1}{3}} = \sqrt{\frac{26}{3}}$$
Si $d = \sqrt{3}$, alors $r = \sqrt{9 - 3} = \sqrt{6}$.
Le centre $H$ est le projeté orthogonal de $\Omega$ sur $(ABC)$.

## Exercice 2

1) Résolution de $z^2 - \sqrt{2}z + 1 = 0$ :
$$\Delta = (-\sqrt{2})^2 - 4(1)(1) = 2 - 4 = -2 = (i\sqrt{2})^2$$
Les solutions sont :
$$z_1 = \frac{\sqrt{2} + i\sqrt{2}}{2} \quad \text{et} \quad z_2 = \frac{\sqrt{2} - i\sqrt{2}}{2}$$
D'où $S = \left\{\frac{\sqrt{2} - i\sqrt{2}}{2}, \frac{\sqrt{2} + i\sqrt{2}}{2}\right\}$.

2) a) $a = \frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2} = \cos\left(\frac{\pi}{4}\right) + i\sin\left(\frac{\pi}{4}\right) = e^{i\frac{\pi}{4}}$.
$$a^{2016} = e^{i \times 2016 \times \frac{\pi}{4}} = e^{i \times 504\pi} = \cos(504\pi) + i\sin(504\pi) = 1 \in \mathbb{R}$$

b)
$$\frac{b}{a} = \frac{\frac{\sqrt{2}}{2} + i\frac{\sqrt{6}}{2}}{\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}} = \frac{1 + i\sqrt{3}}{1 + i} = \frac{(1 + i\sqrt{3})(1 - i)}{2} = \frac{1 - i + i\sqrt{3} + \sqrt{3}}{2} = \frac{1 + \sqrt{3}}{2} + i\frac{\sqrt{3} - 1}{2} \dots$$
En utilisant les modules et arguments : $|b| = \sqrt{2}$, $\arg(b) = \frac{\pi}{3}$, donc $\arg(b/a) = \frac{\pi}{3} - \frac{\pi}{4} = \frac{\pi}{12}$.

## Exercice 3

Nombre total de tirages possibles de 3 boules parmi 8 :
$$\text{Card}(\Omega) = \binom{8}{3} = \frac{8 \times 7 \times 6}{6} = 56$$

1) - $A$ : « 3 boules blanches » :
$$\text{Card}(A) = \binom{4}{3} = 4 \implies p(A) = \frac{4}{56} = \frac{1}{14}$$
- $B$ : « 2 blanches exactement » :
$$\text{Card}(B) = \binom{4}{2} \times \binom{4}{1} = 6 \times 4 = 24 \implies p(B) = \frac{24}{56} = \frac{3}{7}$$

2) a) $X \in \{0, 1, 2, 3\}$.
b) Loi de probabilité :
- $p(X = 0) = \frac{\binom{4}{3}}{56} = \frac{4}{56} = \frac{1}{14}$
- $p(X = 1) = \frac{\binom{4}{1}\binom{4}{2}}{56} = \frac{24}{56} = \frac{3}{7}$
- $p(X = 2) = \frac{24}{56} = \frac{3}{7}$
- $p(X = 3) = \frac{4}{56} = \frac{1}{14}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{1}{14} + 1 \times \frac{3}{7} + 2 \times \frac{3}{7} + 3 \times \frac{1}{14} = \frac{3}{7} + \frac{6}{7} + \frac{3}{14} = \frac{9}{7} + \frac{3}{14} = \frac{21}{14} = \frac{3}{2} = 1,5$$

## Exercice 4

1) Par récurrence :
- $u_0 = 17 > 16$, vrai.
- Supposons $u_n > 16$ :
$$u_{n+1} - 16 = \frac{1}{4}u_n + 12 - 16 = \frac{1}{4}u_n - 4 = \frac{1}{4}(u_n - 16) > 0$$
Donc $u_{n+1} > 16$.
- Conclusion : $u_n > 16$ pour tout $n \in \mathbb{N}$.

2) $u_{n+1} - u_n = \frac{1}{4}u_n + 12 - u_n = -\frac{3}{4}u_n + 12 = -\frac{3}{4}(u_n - 16) < 0$.
La suite $(u_n)$ est strictement décroissante et minorée par 16, donc elle converge.

3) a)
$$v_{n+1} = u_{n+1} - 16 = \frac{1}{4}(u_n - 16) = \frac{1}{4}v_n$$
Donc $(v_n)$ est géométrique de raison $\frac{1}{4}$ et de premier terme $v_0 = u_0 - 16 = 1$.
D'où $v_n = \left(\frac{1}{4}\right)^n$.

b) $u_n = 16 + v_n = 16 + \left(\frac{1}{4}\right)^n$.
Comme $\lim_{n\to +\infty} \left(\frac{1}{4}\right)^n = 0$, on a $\lim_{n\to +\infty} u_n = 16$.

## Problème

### Partie I

1) $g(x) = (1 - x)e^x - 1$.
$g'(x) = -xe^x$.
$g$ est croissante sur $]-\infty, 0]$ et décroissante sur $[0, +\infty[$.
Comme $g(0) = 0$ est le maximum absolu, on a :
$$g(x) \le 0 \quad \text{pour tout } x \in \mathbb{R}$$

### Partie II

1) En $-\infty$ : $\lim_{x\to -\infty} (2 - x)e^x = 0$, donc $\lim_{x\to -\infty} f(x) = +\infty$.
$\lim_{x\to -\infty} [f(x) - (-x + 1)] = \lim_{x\to -\infty} (2 - x)e^x = 0$.
Donc la droite $(D) : y = -x + 1$ est asymptote oblique à $(C_f)$ au voisinage de $-\infty$.

2) En $+\infty$ : $\lim_{x\to +\infty} (2 - x)e^x = -\infty$, donc $\lim_{x\to +\infty} f(x) = -\infty$.
$\lim_{x\to +\infty} \frac{f(x)}{x} = -\infty$, d'où une branche parabolique de direction l’axe des ordonnées au voisinage de $+\infty$.

3) a) $f'(x) = -e^x + (2 - x)e^x - 1 = (1 - x)e^x - 1 = g(x)$.
b) Comme $g(x) \le 0$ pour tout $x$, $f$ est strictement décroissante sur $\mathbb{R}$.

4) Position relative : $f(x) - (-x + 1) = (2 - x)e^x$.
- Sur $]-\infty, 2[$ : $(C_f)$ est au-dessus de $(D)$.
- Sur $]2, +\infty[$ : $(C_f)$ est en dessous de $(D)$.
- En $x = 2$ : $(C_f)$ coupe $(D)$ au point $(2, -1)$.

5) Construction : asymptote oblique à gauche, point d'inflexion en $(0, 3)$, coupe $(D)$ en $(2, -1)$, puis branche parabolique verticale descendante.

6) a) Intégration par parties de $I = \int_0^1 (2 - x)e^x dx$ :
$u = 2 - x \implies u' = -1$, $v' = e^x \implies v = e^x$.
$$I = [(2 - x)e^x]_0^1 - \int_0^1 (-e^x) dx = e - 2 + [e^x]_0^1 = e - 2 + e - 1 = 2e - 3$$

b) Sur $[0, 1]$, $(C_f)$ est au-dessus de $(D)$, donc :
$$\mathcal{A} = \int_0^1 [f(x) - (-x + 1)] dx = I = (2e - 3)\text{ cm}^2$$
