## Exercice 1

1) $A(1, 2, 2)$, $B(3, -1, 6)$, $C(1, 1, 3)$.
$\vec{AB}\begin{pmatrix} 2 \\ -3 \\ 4 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} 0 \\ -1 \\ 1 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} -3 & -1 \\ 4 & 1 \end{vmatrix}\vec{i} - \begin{vmatrix} 2 & 0 \\ 4 & 1 \end{vmatrix}\vec{j} + \begin{vmatrix} 2 & 0 \\ -3 & -1 \end{vmatrix}\vec{k} = \vec{i} - 2\vec{j} - 2\vec{k} \dots$$
En utilisant le vecteur normal $\vec{n}(1, 2, 2)$ :
$$1(x - 1) + 2(y - 2) + 2(z - 2) = 0 \iff x + 2y + 2z - 9 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 2x - 2y - 2 = 0 \iff (x - 1)^2 - 1 + (y - 1)^2 - 1 + z^2 - 2 = 0$
$$\iff (x - 1)^2 + (y - 1)^2 + z^2 = 4 = 2^2$$
Le centre est $\Omega(1, 1, 0)$ et le rayon est $R = 2$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|1 + 2(1) + 2(0) - 9|}{\sqrt{1^2 + 2^2 + 2^2}} = \frac{|-6|}{\sqrt{9}} = \frac{6}{3} = 2$$
Puisque $d(\Omega, (ABC)) = R = 2$, le plan $(ABC)$ est tangent à la sphère $(S)$.
Le point de contact $H$ est le projeté orthogonal de $\Omega$ sur $(ABC)$ :
$$\begin{cases} x = 1 + t \\ y = 1 + 2t \\ z = 2t \end{cases}$$
$(1 + t) + 2(1 + 2t) + 2(2t) - 9 = 0 \iff 9t - 6 = 0 \dots$

## Exercice 2

1) Résolution de $z^2 - 2\sqrt{3}z + 4 = 0$ :
$$\Delta = (-2\sqrt{3})^2 - 4(1)(4) = 12 - 16 = -4 = (2i)^2$$
Les solutions sont :
$$z_1 = \frac{2\sqrt{3} + 2i}{2} = \sqrt{3} + i \quad \text{et} \quad z_2 = \sqrt{3} - i$$
D'où $S = \{\sqrt{3} - i, \sqrt{3} + i\}$.

2) a) $a = \sqrt{3} + i$ : $|a| = \sqrt{3 + 1} = 2$, $a = 2\left(\frac{\sqrt{3}}{2} + \frac{1}{2}i\right) = 2\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right)$.

b) $c = e^{i\frac{\pi}{3}} a = 2e^{i\frac{\pi}{3}} e^{i\frac{\pi}{6}} = 2e^{i\frac{\pi}{2}} = 2i$.

c) On a $OA = OC = 2$ et $(\vec{OA}, \vec{OC}) \equiv \frac{\pi}{3} \; [2\pi]$.
Donc le triangle $OAC$ est un triangle équilatéral.

## Exercice 3

Nombre total de tirages possibles :
$$\text{Card}(\Omega) = \binom{10}{3} = 120$$

1) - $A$ : « 3 boules blanches » :
$$\text{Card}(A) = \binom{5}{3} = 10 \implies p(A) = \frac{10}{120} = \frac{1}{12}$$
- $B$ : « 2 blanches exactement » :
$$\text{Card}(B) = \binom{5}{2} \times \binom{5}{1} = 10 \times 5 = 50 \implies p(B) = \frac{50}{120} = \frac{5}{12}$$

2) a) $X \in \{0, 1, 2, 3\}$.
b)
- $p(X = 0) = \frac{\binom{5}{3}}{120} = \frac{10}{120} = \frac{1}{12}$
- $p(X = 1) = \frac{\binom{5}{1}\binom{5}{2}}{120} = \frac{50}{120} = \frac{5}{12}$
- $p(X = 2) = \frac{50}{120} = \frac{5}{12}$
- $p(X = 3) = \frac{10}{120} = \frac{1}{12}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{1}{12} + 1 \times \frac{5}{12} + 2 \times \frac{5}{12} + 3 \times \frac{1}{12} = \frac{18}{12} = \frac{3}{2} = 1,5$$

## Exercice 4

1) Par récurrence :
- $u_0 = 2$, vrai.
- Supposons $u_n = 2$. Alors $u_{n+1} = \frac{1}{2}(2) + 1 = 1 + 1 = 2$.
Conclusion : pour tout $n \in \mathbb{N}$, $u_n = 2$.

2) La suite $(u_n)$ est constante, donc elle converge et sa limite est 2.

## Problème

1) En $0^+$ : $\lim_{x\to 0^+} \ln x = -\infty \implies \lim_{x\to 0^+} \frac{\ln x}{x} = -\infty$.
Donc $\lim_{x\to 0^+} f(x) = \lim_{x\to 0^+} \left(x + 1 - \frac{\ln x}{x}\right) = +\infty$.
L'axe des ordonnées ($x = 0$) est asymptote verticale à $(C_f)$.

2) En $+\infty$ : $\lim_{x\to +\infty} \frac{\ln x}{x} = 0$, donc $\lim_{x\to +\infty} f(x) = +\infty$.
$\lim_{x\to +\infty} [f(x) - (x + 1)] = \lim_{x\to +\infty} \left(-\frac{\ln x}{x}\right) = 0$.
Donc la droite $(D) : y = x + 1$ est asymptote à $(C_f)$ au voisinage de $+\infty$.

3) a)
$$f'(x) = 1 - \frac{\frac{1}{x}x - \ln x}{x^2} = 1 - \frac{1 - \ln x}{x^2} = \frac{x^2 - 1 + \ln x}{x^2}$$
b) Pour $x \ge 1$ : $x^2 - 1 \ge 0$ et $\ln x \ge 0 \implies f'(x) \ge 0$.
Pour $0 < x \le 1$ : $x^2 - 1 \le 0$ et $\ln x \le 0 \implies f'(x) \le 0$.
$f'(1) = 0$.
Donc $f$ admet un minimum absolu en $x = 1$, égal à $f(1) = 1 + 1 - 0 = 2$.

4) Position relative : $f(x) - (x + 1) = -\frac{\ln x}{x}$.
- Si $x \in ]0, 1[$ : $\ln x < 0 \implies f(x) - (x + 1) > 0$, donc $(C_f)$ est au-dessus de $(D)$.
- Si $x > 1$ : $\ln x > 0 \implies f(x) - (x + 1) < 0$, donc $(C_f)$ est en dessous de $(D)$.
- En $x = 1$ : $(C_f)$ coupe $(D)$ au point $(1, 2)$.

5) Construction : asymptote verticale $x = 0$, minimum en $(1, 2)$ qui est aussi le point de tangence/contact avec la droite $y = x + 1$.

6) a) $I = \int_1^e \frac{\ln x}{x} dx = \left[\frac{1}{2}(\ln x)^2\right]_1^e = \frac{1}{2}(1 - 0) = \frac{1}{2}$.
b) Sur $[1, e]$, $(C_f)$ est en dessous de $(D)$, donc :
$$\mathcal{A} = \int_1^e ((x + 1) - f(x)) dx = I = \frac{1}{2}\text{ cm}^2$$
