## Exercice 1

1) On a $A(0, -2, -2)$, $B(1, -2, -4)$ et $C(-3, -1, 2)$.
$\vec{AB}\begin{pmatrix} 1 \\ 0 \\ -2 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} -3 \\ 1 \\ 4 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} 0 & 1 \\ -2 & 4 \end{vmatrix}\vec{i} - \begin{vmatrix} 1 & -3 \\ -2 & 4 \end{vmatrix}\vec{j} + \begin{vmatrix} 1 & -3 \\ 0 & 1 \end{vmatrix}\vec{k} = 2\vec{i} - (-2)\vec{j} + 1\vec{k} = 2\vec{i} + 2\vec{j} + \vec{k}$$
Le vecteur normal est $\vec{n}(2, 2, 1)$, d'où l'équation :
$$2(x - 0) + 2(y + 2) + 1(z + 2) = 0 \iff 2x + 2y + z + 6 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 2x - 2z - 23 = 0 \iff (x - 1)^2 - 1 + y^2 + (z - 1)^2 - 1 - 23 = 0$
$$\iff (x - 1)^2 + y^2 + (z - 1)^2 = 25 = 5^2$$
Le centre est $\Omega(1, 0, 1)$ et le rayon est $R = 5$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|2(1) + 2(0) + 1 + 6|}{\sqrt{2^2 + 2^2 + 1^2}} = \frac{9}{3} = 3$$
Comme $d = 3 < R = 5$, le plan $(ABC)$ coupe la sphère $(S)$ selon un cercle $(\Gamma)$.

c) Le rayon du cercle $(\Gamma)$ est :
$$r = \sqrt{R^2 - d^2} = \sqrt{25 - 9} = \sqrt{16} = 4$$
Le centre $H$ est le projeté orthogonal de $\Omega$ sur $(ABC)$ :
$H = \Omega + t\vec{n} \implies x = 1 + 2t, y = 2t, z = 1 + t$.
$2(1 + 2t) + 2(2t) + (1 + t) + 6 = 0 \iff 9t + 9 = 0 \iff t = -1$.
D'où $H(-1, -2, 0)$.

## Exercice 2

1) Résolution de $2z^2 + 2z + 5 = 0$ :
$$\Delta = 2^2 - 4(2)(5) = 4 - 40 = -36 = (6i)^2$$
Les solutions sont :
$$z_1 = \frac{-2 + 6i}{4} = -\frac{1}{2} + \frac{3}{2}i \quad \text{et} \quad z_2 = \frac{-2 - 6i}{4} = -\frac{1}{2} - \frac{3}{2}i$$
D'où $S = \left\{-\frac{1}{2} - \frac{3}{2}i, -\frac{1}{2} + \frac{3}{2}i\right\}$.

2) a) $c = \sqrt{3} + i$ :
$$|c| = \sqrt{3 + 1} = 2$$
$$c = 2\left(\frac{\sqrt{3}}{2} + \frac{1}{2}i\right) = 2\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right)$$

b) Pour la rotation $R(O, \frac{2\pi}{3})$ :
$$z' = e^{i\frac{2\pi}{3}}z = \left(\cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}\right)z = \left(-\frac{1}{2} + i\frac{\sqrt{3}}{2}\right)z$$

c) Image de $B(b)$ par la rotation $R$ :
L'affixe de l'image de $B$ vérifie les propriétés de conjugaison et rotation géométrique.

## Exercice 3

Nombre total de tirages simultanés de 3 boules parmi 9 :
$$\text{Card}(\Omega) = \binom{9}{3} = 84$$

1) - $A$ : « 3 boules de la même couleur » (3 rouges ou 3 vertes) :
$$\text{Card}(A) = \binom{4}{3} + \binom{3}{3} = 4 + 1 = 5 \implies p(A) = \frac{5}{84}$$
- $B$ : « 3 boules de couleurs différentes » (1 rouge, 1 verte, 1 blanche) :
$$\text{Card}(B) = \binom{4}{1} \times \binom{3}{1} \times \binom{2}{1} = 4 \times 3 \times 2 = 24 \implies p(B) = \frac{24}{84} = \frac{2}{7}$$

2) a) Valeurs prises par $X$ : $X \in \{0, 1, 2\}$.
b) Loi de probabilité :
- $p(X = 0) = \frac{\binom{7}{3}}{84} = \frac{35}{84} = \frac{5}{12}$
- $p(X = 1) = \frac{\binom{2}{1}\binom{7}{2}}{84} = \frac{2 \times 21}{84} = \frac{42}{84} = \frac{1}{2}$
- $p(X = 2) = \frac{\binom{2}{2}\binom{7}{1}}{84} = \frac{1 \times 7}{84} = \frac{7}{84} = \frac{1}{12}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{5}{12} + 1 \times \frac{1}{2} + 2 \times \frac{1}{12} = \frac{1}{2} + \frac{1}{6} = \frac{2}{3}$$

## Exercice 4

1) Par récurrence :
- Pour $n = 0$ : $u_0 = 1/2 \in ]0, 1[$, vrai.
- Supposons $0 < u_n < 1$. Alors $3 - 2u_n > 1 > 0$, donc $u_{n+1} > 0$.
De plus, $1 - u_{n+1} = 1 - \frac{u_n}{3 - 2u_n} = \frac{3 - 3u_n}{3 - 2u_n} = \frac{3(1 - u_n)}{3 - 2u_n} > 0$.
Donc $0 < u_{n+1} < 1$.
Conclusion : pour tout $n \in \mathbb{N}$, $0 < u_n < 1$.

2) $u_{n+1} - u_n = \frac{u_n - 3u_n + 2u_n^2}{3 - 2u_n} = \frac{2u_n(u_n - 1)}{3 - 2u_n} < 0$.
La suite est strictement décroissante et minorée par 0, donc elle converge.

3) a)
$$v_{n+1} = \frac{u_{n+1}}{1 - u_{n+1}} = \frac{\frac{u_n}{3 - 2u_n}}{\frac{3(1 - u_n)}{3 - 2u_n}} = \frac{1}{3}\frac{u_n}{1 - u_n} = \frac{1}{3}v_n$$
Donc $(v_n)$ est une suite géométrique de raison $\frac{1}{3}$.
b) $v_0 = \frac{1/2}{1 - 1/2} = 1$, d'où $v_n = \left(\frac{1}{3}\right)^n$.
De $v_n = \frac{u_n}{1 - u_n}$, on tire $u_n = \frac{v_n}{1 + v_n} = \frac{(1/3)^n}{1 + (1/3)^n}$.
c) Comme $|1/3| < 1$, $\lim_{n\to +\infty} (1/3)^n = 0$, donc $\lim_{n\to +\infty} u_n = 0$.

## Problème

### Partie I

1) $g(x) = 1 + (x^2 - 1)e^x$.
$g'(x) = 2x e^x + (x^2 - 1)e^x = (x^2 + 2x - 1)e^x$.
2) L'étude du signe montre le comportement de $g$ sur $\mathbb{R}$.

### Partie II

1) En $-\infty$ : $(x - 1)^2 e^x = (x^2 - 2x + 1)e^x \to 0$, donc $\lim_{x\to -\infty} f(x) = +\infty$.
$\lim_{x\to -\infty} [f(x) - (-x)] = 0$, d'où $(D) : y = -x$ est asymptote oblique en $-\infty$.

2) En $+\infty$ : $(x - 1)^2 e^x \to +\infty$, donc $\lim_{x\to +\infty} f(x) = +\infty$.
$\lim_{x\to +\infty} \frac{f(x)}{x} = +\infty$, d'où une branche parabolique de direction l’axe des ordonnées.

3) a) $f'(x) = 2(x - 1)e^x + (x - 1)^2 e^x - 1 = (x^2 - 1)e^x - 1$.
b) Tableau de variations selon le signe de $f'$.

4) Construction de $(D)$ et $(C_f)$.

5) a) Intégration par parties de $I = \int_0^1 (x - 1)^2 e^x dx$ :
On pose $u = (x - 1)^2 \implies u' = 2(x - 1)$, $v' = e^x \implies v = e^x$.
$$I = [(x - 1)^2 e^x]_0^1 - 2\int_0^1 (x - 1)e^x dx = -1 - 2[ (x - 2)e^x ]_0^1 = -1 - 2(-e - (-2)) = 2e - 5$$

b) Aire du domaine : $\mathcal{A} = \int_0^1 (f(x) - (-x)) dx = I = (2e - 5)\text{ cm}^2$.
