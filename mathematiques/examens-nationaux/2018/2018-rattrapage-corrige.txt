## Exercice 1

1) $A(1, 1, 1)$, $B(2, 3, 0)$ et $C(0, 1, 3)$.
$\vec{AB}\begin{pmatrix} 1 \\ 2 \\ -1 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} -1 \\ 0 \\ 2 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} 2 & 0 \\ -1 & 2 \end{vmatrix}\vec{i} - \begin{vmatrix} 1 & -1 \\ -1 & 2 \end{vmatrix}\vec{j} + \begin{vmatrix} 1 & -1 \\ 2 & 0 \end{vmatrix}\vec{k} = 4\vec{i} - 1\vec{j} + 2\vec{k} \dots$$
Avec le résultat $\vec{n}(2, 1, 2)$ :
$$2(x - 1) + 1(y - 1) + 2(z - 1) = 0 \iff 2x + y + 2z - 5 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 2x - 4y + 2z - 3 = 0 \iff (x - 1)^2 - 1 + (y - 2)^2 - 4 + (z + 1)^2 - 1 - 3 = 0$
$$\iff (x - 1)^2 + (y - 2)^2 + (z + 1)^2 = 9 = 3^2$$
Le centre est $\Omega(1, 2, -1)$ et le rayon est $R = 3$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|2(1) + 2 + 2(-1) - 5|}{\sqrt{2^2 + 1^2 + 2^2}} = \frac{|-3|}{3} = 1$$
Comme $d = 1 < R = 3$, le plan $(ABC)$ coupe la sphère $(S)$ selon un cercle $(\Gamma)$.

c) Le rayon du cercle $(\Gamma)$ est :
$$r = \sqrt{R^2 - d^2} = \sqrt{3^2 - 1^2} = \sqrt{8} = 2\sqrt{2}$$

## Exercice 2

1) Résolution de $z^2 - 2\sqrt{2}z + 4 = 0$ :
$$\Delta = (-2\sqrt{2})^2 - 4(1)(4) = 8 - 16 = -8 = (2i\sqrt{2})^2$$
Les solutions sont :
$$z_1 = \frac{2\sqrt{2} + 2i\sqrt{2}}{2} = \sqrt{2} + i\sqrt{2} \quad \text{et} \quad z_2 = \sqrt{2} - i\sqrt{2}$$
D'où $S = \{\sqrt{2} - i\sqrt{2}, \sqrt{2} + i\sqrt{2}\}$.

2) a) $a = \sqrt{2} + i\sqrt{2}$ : $|a| = 2$, $a = 2\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$.
$b = 1 + i\sqrt{3}$ : $|b| = 2$, $b = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$.

b) $a^{12} = \left[2e^{i\frac{\pi}{4}}\right]^{12} = 2^{12} e^{i 3\pi} = 4096(-1) = -4096 \in \mathbb{R}$.

c) Quotient $\frac{a}{b}$ :
$$\frac{a}{b} = \frac{2e^{i\frac{\pi}{4}}}{2e^{i\frac{\pi}{3}}} = e^{i(\frac{\pi}{4} - \frac{\pi}{3})} = e^{-i\frac{\pi}{12}} = \cos\left(-\frac{\pi}{12}\right) + i\sin\left(-\frac{\pi}{12}\right)$$

## Exercice 3

Nombre de boules : 10 (6 blanches, 4 noires).
Tirage simultané de 3 boules :
$$\text{Card}(\Omega) = \binom{10}{3} = 120$$

1) - $A$ : « 3 boules blanches » :
$$\text{Card}(A) = \binom{6}{3} = 20 \implies p(A) = \frac{20}{120} = \frac{1}{6}$$
- $B$ : « 2 blanches exactement » :
$$\text{Card}(B) = \binom{6}{2} \times \binom{4}{1} = 15 \times 4 = 60 \implies p(B) = \frac{60}{120} = \frac{1}{2}$$

2) a) Valeurs prises par $X$ : $X \in \{0, 1, 2, 3\}$.
b) Loi de probabilité :
- $p(X = 0) = \frac{\binom{4}{3}}{120} = \frac{4}{120} = \frac{1}{30}$
- $p(X = 1) = \frac{\binom{6}{1}\binom{4}{2}}{120} = \frac{6 \times 6}{120} = \frac{36}{120} = \frac{3}{10}$
- $p(X = 2) = \frac{60}{120} = \frac{1}{2}$
- $p(X = 3) = \frac{20}{120} = \frac{1}{6}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{4}{120} + 1 \times \frac{36}{120} + 2 \times \frac{60}{120} + 3 \times \frac{20}{120} = \frac{36 + 120 + 60}{120} = \frac{216}{120} = \frac{9}{5} = 1,8$$

## Exercice 4

1) Par récurrence :
- $u_0 = 1 > 0$, vrai.
- Supposons $u_n > 0$. Alors $2 + u_n > 2 > 0$, d'où $u_{n+1} = \frac{u_n}{2 + u_n} > 0$.
Donc pour tout $n \in \mathbb{N}$, $u_n > 0$.

2) $u_{n+1} - u_n = \frac{u_n - 2u_n - u_n^2}{2 + u_n} = \frac{-u_n - u_n^2}{2 + u_n} = \frac{-u_n(1 + u_n)}{2 + u_n} < 0$.
La suite est strictement décroissante et minorée par 0, donc elle converge.

3) a)
$$v_{n+1} = \frac{1}{u_{n+1}} + 1 = \frac{2 + u_n}{u_n} + 1 = \frac{2}{u_n} + 1 + 1 = 2\left(\frac{1}{u_n} + 1\right) = 2v_n$$
Donc $(v_n)$ est une suite géométrique de raison 2.
b) $v_0 = \frac{1}{u_0} + 1 = 1 + 1 = 2$, d'où $v_n = 2 \times 2^n = 2^{n+1}$.
De $v_n = \frac{1}{u_n} + 1$, on tire $\frac{1}{u_n} = v_n - 1 \iff u_n = \frac{1}{2^{n+1} - 1}$.
c) Comme $\lim_{n\to +\infty} 2^{n+1} = +\infty$, on a $\lim_{n\to +\infty} u_n = 0$.

## Problème

1) En $-\infty$ : $(x - 2)e^x = xe^x - 2e^x \to 0$, donc $\lim_{x\to -\infty} f(x) = -\infty$.
$\lim_{x\to -\infty} [f(x) - x] = \lim_{x\to -\infty} (x - 2)e^x = 0$.
Donc $(D) : y = x$ est asymptote oblique à $(C_f)$ au voisinage de $-\infty$.

2) En $+\infty$ : $\lim_{x\to +\infty} (x - 2)e^x = +\infty$, donc $\lim_{x\to +\infty} f(x) = +\infty$.
$\lim_{x\to +\infty} \frac{f(x)}{x} = +\infty$, branche parabolique de direction l’axe des ordonnées.

3) a) $f'(x) = 1 \cdot e^x + (x - 2)e^x + 1 = (x - 1)e^x + 1$.
b) Comme $(x - 1)e^x + 1 \ge 0$ pour tout $x \in \mathbb{R}$, $f$ est strictement croissante sur $\mathbb{R}$.

4) Position relative : $f(x) - x = (x - 2)e^x$.
- Si $x < 2$ : $(C_f)$ est en dessous de $(D)$.
- Si $x > 2$ : $(C_f)$ est au-dessus de $(D)$.
- En $x = 2$ : $(C_f)$ coupe $(D)$ au point $(2, 2)$.

5) Construction : asymptote $y = x$ à gauche, coupe la droite en $(2, 2)$, puis s'élève rapidement en $+\infty$.

6) a) $I = \int_0^2 (x - 2)e^x dx$ :
$u = x - 2 \implies u' = 1$, $v' = e^x \implies v = e^x$.
$$I = [(x - 2)e^x]_0^2 - \int_0^2 e^x dx = 2 - (e^2 - 1) = 3 - e^2$$

b) Sur $[0, 2]$, $(C_f)$ est en dessous de $(D)$, donc :
$$\mathcal{A} = \int_0^2 (x - f(x)) dx = -I = (e^2 - 3)\text{ cm}^2$$
