## Exercice 1

1) $A(0, 1, 1)$, $B(1, 2, 0)$, $C(-1, 1, 2)$.
$\vec{AB}\begin{pmatrix} 1 \\ 1 \\ -1 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} -1 \\ 0 \\ 1 \end{pmatrix}$.
Le produit vectoriel donne $\vec{AB} \wedge \vec{AC} = \vec{i} + \vec{j} + \vec{k}$.
Équation du plan $(ABC)$ :
$$1(x - 0) + 1(y - 1) + 1(z - 1) = 0 \iff x + y + z - 2 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 2x - 4y - 4 = 0 \iff (x - 1)^2 + (y - 2)^2 + z^2 = 9 = 3^2$.
Le centre est $\Omega(1, 2, 0)$ et le rayon est $R = 3$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|1 + 2 + 0 - 2|}{\sqrt{1^2 + 1^2 + 1^2}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$
Comme $d < R = 3$, le plan $(ABC)$ coupe la sphère $(S)$ selon un cercle $(\Gamma)$.

c) Le rayon du cercle est :
$$r = \sqrt{R^2 - d^2} = \sqrt{9 - \frac{1}{3}} = \sqrt{\frac{26}{3}} = \frac{\sqrt{78}}{3}$$
Le centre $H$ est le projeté orthogonal de $\Omega$ sur $(ABC)$ :
$\begin{cases} x = 1 + t \\ y = 2 + t \\ z = t \end{cases}$ avec $(1+t) + (2+t) + t - 2 = 0 \iff 3t + 1 = 0 \iff t = -1/3$.
D'où $H(2/3, 5/3, -1/3)$.

## Exercice 2

1) Résolution de $z^2 - \sqrt{2}z + 1 = 0$ :
$$\Delta = (-\sqrt{2})^2 - 4(1)(1) = 2 - 4 = -2 = (i\sqrt{2})^2$$
Les solutions sont :
$$z_1 = \frac{\sqrt{2} + i\sqrt{2}}{2} \quad \text{et} \quad z_2 = \frac{\sqrt{2} - i\sqrt{2}}{2}$$
D'où $S = \left\{\frac{\sqrt{2} - i\sqrt{2}}{2}, \frac{\sqrt{2} + i\sqrt{2}}{2}\right\}$.

2) a) $a = \frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2} = \cos\frac{\pi}{4} + i\sin\frac{\pi}{4} = e^{i\frac{\pi}{4}}$.

b) $b = e^{i\frac{\pi}{3}}$, donc :
$$ab = e^{i\frac{\pi}{4}} e^{i\frac{\pi}{3}} = e^{i(\frac{\pi}{4} + \frac{\pi}{3})} = e^{i\frac{7\pi}{12}} = \cos\frac{7\pi}{12} + i\sin\frac{7\pi}{12}$$

c) Image de $A(a)$ par la rotation $R(O, \frac{\pi}{3})$ :
L'affixe de l'image est $z' = e^{i\frac{\pi}{3}}a = ab = \cos\frac{7\pi}{12} + i\sin\frac{7\pi}{12}$.

## Exercice 3

Nombre total de tirages possibles de 3 jetons parmi 9 :
$$\text{Card}(\Omega) = \binom{9}{3} = 84$$

1) - $A$ : « 3 blancs » :
$$\text{Card}(A) = \binom{5}{3} = 10 \implies p(A) = \frac{10}{84} = \frac{5}{42}$$
- $B$ : « portant le numéro 2 » (il y a 4 jetons avec le numéro 2 : 2 blancs, 2 noirs) :
$$\text{Card}(B) = \binom{4}{3} = 4 \implies p(B) = \frac{4}{84} = \frac{1}{21}$$

2) a) $X \in \{0, 1, 2, 3\}$.
b) Loi de probabilité :
- $p(X = 0) = \frac{\binom{4}{3}}{84} = \frac{4}{84} = \frac{1}{21}$
- $p(X = 1) = \frac{\binom{5}{1}\binom{4}{2}}{84} = \frac{5 \times 6}{84} = \frac{30}{84} = \frac{5}{14}$
- $p(X = 2) = \frac{\binom{5}{2}\binom{4}{1}}{84} = \frac{10 \times 4}{84} = \frac{40}{84} = \frac{10}{21}$
- $p(X = 3) = \frac{\binom{5}{3}}{84} = \frac{10}{84} = \frac{5}{42}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{4}{84} + 1 \times \frac{30}{84} + 2 \times \frac{40}{84} + 3 \times \frac{10}{84} = \frac{30 + 80 + 30}{84} = \frac{140}{84} = \frac{5}{3}$$

## Exercice 4

1) Par récurrence :
- $u_0 = 1/2 \in ]0, 1[$, vrai.
- Supposons $0 < u_n < 1$. Alors $2 - u_n > 1 > 0$, donc $u_{n+1} > 0$.
$1 - u_{n+1} = 1 - \frac{u_n}{2 - u_n} = \frac{2 - 2u_n}{2 - u_n} = \frac{2(1 - u_n)}{2 - u_n} > 0$.
Donc $0 < u_{n+1} < 1$.
Conclusion : pour tout $n \in \mathbb{N}$, $0 < u_n < 1$.

2) $u_{n+1} - u_n = \frac{u_n - 2u_n + u_n^2}{2 - u_n} = \frac{u_n(u_n - 1)}{2 - u_n} < 0$.
La suite est strictement décroissante et minorée par 0, donc elle converge.

3) a)
$$v_{n+1} = \frac{1}{u_{n+1}} - 1 = \frac{2 - u_n}{u_n} - 1 = \frac{2 - 2u_n}{u_n} = 2\left(\frac{1}{u_n} - 1\right) = 2v_n$$
Donc $(v_n)$ est une suite géométrique de raison 2.
b) $v_0 = \frac{1}{1/2} - 1 = 1$, d'où $v_n = 2^n$.
De $v_n = \frac{1}{u_n} - 1$, on tire $u_n = \frac{1}{2^n + 1}$.
c) Comme $\lim_{n\to +\infty} 2^n = +\infty$, on a $\lim_{n\to +\infty} u_n = 0$.

## Problème

1) En $-\infty$ : $(x - 1)^2 e^x \to 0$, donc $\lim_{x\to -\infty} f(x) = -1$.
La droite d'équation $y = -1$ est asymptote horizontale à $(C_f)$ au voisinage de $-\infty$.

2) En $+\infty$ : $\lim_{x\to +\infty} f(x) = +\infty$ et $\lim_{x\to +\infty} \frac{f(x)}{x} = +\infty$.
Branche parabolique de direction l’axe des ordonnées au voisinage de $+\infty$.

3) a) $f'(x) = 2(x - 1)e^x + (x - 1)^2 e^x = (x^2 - 1)e^x$.
b) Signe de $f'(x)$ : celui de $x^2 - 1$.
$f$ est croissante sur $]-\infty, -1]$, décroissante sur $[-1, 1]$, et croissante sur $[1, +\infty[$.
$f(-1) = 4e^{-1} - 1$, $f(1) = -1$.

4) Points d'intersection :
- Avec l'axe des ordonnées : $f(0) = 1 - 1 = 0$, donc $(0, 0)$.
- Avec l'axe des abscisses : $f(x) = 0 \iff (x - 1)^2 e^x = 1$. L'une des racines est $x = 0$.

5) Construction de $(C_f)$.

6) a) Intégration par parties :
$$I = \int_0^1 (x - 1)^2 e^x dx = [(x - 1)^2 e^x]_0^1 - 2\int_0^1 (x - 1)e^x dx = -1 - 2[(x - 2)e^x]_0^1 = -1 - 2(-e + 2) = 2e - 5$$

b) Aire du domaine :
$$\mathcal{A} = \int_0^1 |f(x)| dx = \int_0^1 (1 - (x - 1)^2 e^x) dx = 1 - I = 1 - (2e - 5) = (6 - 2e)\text{ cm}^2$$
