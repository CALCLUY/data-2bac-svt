## Exercice 1

1) $A(2, 1, 0)$, $B(0, 1, 2)$, $C(1, 0, 1)$.
$\vec{AB}\begin{pmatrix} -2 \\ 0 \\ 2 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} -1 \\ -1 \\ 1 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} 0 & -1 \\ 2 & 1 \end{vmatrix}\vec{i} - \begin{vmatrix} -2 & -1 \\ 2 & 1 \end{vmatrix}\vec{j} + \begin{vmatrix} -2 & -1 \\ 0 & -1 \end{vmatrix}\vec{k} = 2\vec{i} - 0\vec{j} + 2\vec{k} \dots$$
Avec le vecteur normal $\vec{n}(1, 1, 1)$ :
$$1(x - 2) + 1(y - 1) + 1(z - 0) = 0 \iff x + y + z - 3 = 0$$

2) a) $(S) : (x - 1)^2 + (y - 1)^2 + (z - 1)^2 = 4 = 2^2$.
Le centre est $\Omega(1, 1, 1)$ et le rayon est $R = 2$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|1 + 1 + 1 - 3|}{\sqrt{1^2 + 1^2 + 1^2}} = 0$$
Le centre $\Omega$ appartient au plan $(ABC)$, donc l'intersection est un grand cercle de centre $\Omega(1, 1, 1)$ et de rayon $r = R = 2$.

## Exercice 2

1) Résolution de $z^2 - 4z + 8 = 0$ :
$$\Delta = (-4)^2 - 4(1)(8) = 16 - 32 = -16 = (4i)^2$$
Les solutions sont :
$$z_1 = \frac{4 + 4i}{2} = 2 + 2i \quad \text{et} \quad z_2 = 2 - 2i$$
D'où $S = \{2 - 2i, 2 + 2i\}$.

2) a) $a = 2 + 2i = 2\sqrt{2}\left(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right) = 2\sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$.

b) Calcul de $\frac{c - b}{a - b}$ avec $a = 2 + 2i, b = 2 - 2i, c = 4$ :
$$\frac{c - b}{a - b} = \frac{4 - (2 - 2i)}{(2 + 2i) - (2 - 2i)} = \frac{2 + 2i}{4i} = \frac{2(1 + i)}{4i} = \frac{1 + i}{2i} = \frac{(1 + i)(-i)}{2} = \frac{1 - i}{2} \dots$$

## Exercice 3

Nombre total de tirages possibles de 3 boules parmi 10 :
$$\text{Card}(\Omega) = \binom{10}{3} = 120$$

1) - $A$ : « 3 boules rouges » :
$$\text{Card}(A) = \binom{4}{3} = 4 \implies p(A) = \frac{4}{120} = \frac{1}{30}$$
- $B$ : « 2 vertes exactement » (2 vertes et 1 rouge) :
$$\text{Card}(B) = \binom{6}{2} \times \binom{4}{1} = 15 \times 4 = 60 \implies p(B) = \frac{60}{120} = \frac{1}{2}$$

2) a) $X \in \{0, 1, 2, 3\}$.
b) Loi de probabilité :
- $p(X = 0) = \frac{\binom{6}{3}}{120} = \frac{20}{120} = \frac{1}{6}$
- $p(X = 1) = \frac{\binom{4}{1}\binom{6}{2}}{120} = \frac{60}{120} = \frac{1}{2}$
- $p(X = 2) = \frac{\binom{4}{2}\binom{6}{1}}{120} = \frac{36}{120} = \frac{3}{10}$
- $p(X = 3) = \frac{4}{120} = \frac{1}{30}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{20}{120} + 1 \times \frac{60}{120} + 2 \times \frac{36}{120} + 3 \times \frac{4}{120} = \frac{60 + 72 + 12}{120} = \frac{144}{120} = \frac{6}{5} = 1,2$$

## Exercice 4

1) Par récurrence :
- $u_0 = 2$, vrai.
- Supposons $u_n = 2$. Alors $u_{n+1} = \frac{1}{2}(2) + 1 = 2$.
Conclusion : pour tout $n \in \mathbb{N}$, $u_n = 2$.

2) La suite est constante, donc elle converge et $\lim_{n\to +\infty} u_n = 2$.

## Problème

1) En $0^+$ : $\lim_{x\to 0^+} \frac{\ln x}{x} = -\infty$, donc $\lim_{x\to 0^+} f(x) = -\infty$.
L'axe des ordonnées ($x = 0$) est asymptote verticale à $(C_f)$.

2) En $+\infty$ : $\lim_{x\to +\infty} \frac{\ln x}{x} = 0$, donc $\lim_{x\to +\infty} f(x) = +\infty$.
$\lim_{x\to +\infty} [f(x) - (x - 1)] = 0$.
La droite $(D) : y = x - 1$ est asymptote oblique à $(C_f)$ au voisinage de $+\infty$.

3) a) Pour $x > 0$ :
$$f'(x) = 1 + \frac{1 - \ln x}{x^2} = \frac{x^2 + 1 - \ln x}{x^2}$$
b) Comme $x^2 + 1 - \ln x > 0$ pour tout $x > 0$, $f'(x) > 0$.
Donc $f$ est strictement croissante sur $]0, +\infty[$.

4) Position relative : $f(x) - (x - 1) = \frac{\ln x}{x}$.
- Si $x \in ]0, 1[$ : $\ln x < 0 \implies (C_f)$ est en dessous de $(D)$.
- Si $x > 1$ : $\ln x > 0 \implies (C_f)$ est au-dessus de $(D)$.
- En $x = 1$ : $(C_f)$ coupe $(D)$ au point $(1, 0)$.

5) Construction de $(C_f)$ et $(D)$.

6) a) $I = \int_1^e \frac{\ln x}{x} dx = \left[\frac{1}{2}(\ln x)^2\right]_1^e = \frac{1}{2}$.
b) Aire du domaine :
$$\mathcal{A} = \int_1^e (f(x) - (x - 1)) dx = I = \frac{1}{2}\text{ cm}^2 = 0,5\text{ cm}^2$$
