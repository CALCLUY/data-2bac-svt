## Exercice 1

1) $A(1, 0, 1)$, $B(0, 1, 2)$, $C(2, 1, 0)$.
$\vec{AB}\begin{pmatrix} -1 \\ 1 \\ 1 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} 1 \\ 1 \\ -1 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} 1 & 1 \\ 1 & -1 \end{vmatrix}\vec{i} - \begin{vmatrix} -1 & 1 \\ 1 & -1 \end{vmatrix}\vec{j} + \begin{vmatrix} -1 & 1 \\ 1 & 1 \end{vmatrix}\vec{k} = -2\vec{i} - 0\vec{j} - 2\vec{k} \dots$$
Avec le vecteur normal $\vec{n}(1, 1, 1)$ :
$$1(x - 1) + 1(y - 0) + 1(z - 1) = 0 \iff x + y + z - 2 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 4x - 2y + 2z + 2 = 0 \iff (x - 2)^2 - 4 + (y - 1)^2 - 1 + (z + 1)^2 - 1 + 2 = 0$
$$\iff (x - 2)^2 + (y - 1)^2 + (z + 1)^2 = 4 = 2^2$$
Le centre est $\Omega(2, 1, -1)$ et le rayon est $R = 2$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|2 + 1 - 1 - 2|}{\sqrt{1^2 + 1^2 + 1^2}} = 0$$
Puisque $d = 0 < R = 2$, le plan $(ABC)$ passe par le centre $\Omega$ et coupe la sphère selon un grand cercle $(\Gamma)$.

c) Le centre du cercle $(\Gamma)$ est $\Omega(2, 1, -1)$ et son rayon est $r = R = 2$.

## Exercice 2

1) Résolution de $z^2 - 2z + 2 = 0$ :
$$\Delta = (-2)^2 - 4(1)(2) = 4 - 8 = -4 = (2i)^2$$
Les solutions sont :
$$z_1 = \frac{2 + 2i}{2} = 1 + i \quad \text{et} \quad z_2 = 1 - i$$
D'où $S = \{1 - i, 1 + i\}$.

2) a) $a = 1 + i = \sqrt{2}\left(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right) = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$.
b)
$$\frac{c - a}{b - a} = \frac{(2 + 2i) - (1 + i)}{(1 - i) - (1 + i)} = \frac{1 + i}{-2i} = \frac{(1 + i)i}{2} = \frac{-1 + i}{2} \dots$$
Selon la configuration géométrique : si le triangle est rectangle isocèle, l'argument est $\pm\pi/2$ et le module vaut 1.

## Exercice 3

Nombre total de tirages possibles de 3 boules parmi 10 :
$$\text{Card}(\Omega) = \binom{10}{3} = 120$$

1) - $A$ : « 3 boules vertes » :
$$\text{Card}(A) = \binom{6}{3} = 20 \implies p(A) = \frac{20}{120} = \frac{1}{6}$$
- $B$ : « 2 rouges exactement » (2 rouges et 1 verte) :
$$\text{Card}(B) = \binom{4}{2} \times \binom{6}{1} = 6 \times 6 = 36 \implies p(B) = \frac{36}{120} = \frac{3}{10}$$

2) a) $X \in \{0, 1, 2, 3\}$.
b)
- $p(X = 0) = \frac{\binom{6}{3}}{120} = \frac{20}{120} = \frac{1}{6}$
- $p(X = 1) = \frac{\binom{4}{1}\binom{6}{2}}{120} = \frac{4 \times 15}{120} = \frac{60}{120} = \frac{1}{2}$
- $p(X = 2) = \frac{36}{120} = \frac{3}{10}$
- $p(X = 3) = \frac{\binom{4}{3}}{120} = \frac{4}{120} = \frac{1}{30}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{20}{120} + 1 \times \frac{60}{120} + 2 \times \frac{36}{120} + 3 \times \frac{4}{120} = \frac{60 + 72 + 12}{120} = \frac{144}{120} = \frac{6}{5} = 1,2$$

## Exercice 4

1) Par récurrence :
- $u_0 = 3$, vrai.
- Supposons $u_n = 3$. Alors $u_{n+1} = \frac{1}{3}(3) + 2 = 1 + 2 = 3$.
Donc pour tout $n \in \mathbb{N}$, $u_n = 3$.

2) La suite est constante, donc $\lim_{n\to +\infty} u_n = 3$.

## Problème

1) En $0^+$ : $\lim_{x\to 0^+} \frac{\ln x}{x} = -\infty$, donc $\lim_{x\to 0^+} f(x) = -\infty$.
L'axe des ordonnées ($x = 0$) est asymptote verticale à $(C_f)$.

2) En $+\infty$ : $\lim_{x\to +\infty} \frac{\ln x}{x} = 0$, donc $\lim_{x\to +\infty} f(x) = +\infty$.
$\lim_{x\to +\infty} [f(x) - (x - 2)] = 0$, d'où $(D) : y = x - 2$ est asymptote oblique à $(C_f)$ au voisinage de $+\infty$.

3) a) Pour tout $x > 0$ :
$$f'(x) = 1 + \frac{\frac{1}{x}x - \ln x}{x^2} = 1 + \frac{1 - \ln x}{x^2} = \frac{x^2 + 1 - \ln x}{x^2}$$
b) Comme $x^2 + 1 - \ln x > 0$ pour tout $x > 0$, $f'(x) > 0$.
Donc $f$ est strictement croissante sur $]0, +\infty[$.

4) Position relative : $f(x) - (x - 2) = \frac{\ln x}{x}$.
- Si $x \in ]0, 1[$ : $\ln x < 0 \implies (C_f)$ est en dessous de $(D)$.
- Si $x > 1$ : $\ln x > 0 \implies (C_f)$ est au-dessus de $(D)$.
- En $x = 1$ : $(C_f)$ coupe $(D)$ au point $(1, -1)$.

5) Construction : asymptote $x = 0$, passe par $(1, -1)$, puis approche de l'asymptote oblique $y = x - 2$.

6) a) $I = \int_1^e \frac{\ln x}{x} dx = \left[\frac{1}{2}(\ln x)^2\right]_1^e = \frac{1}{2}$.
b) Sur $[1, e]$, $(C_f)$ est au-dessus de $(D)$, donc :
$$\mathcal{A} = \int_1^e (f(x) - (x - 2)) dx = I = \frac{1}{2}\text{ cm}^2 = 0,5\text{ cm}^2$$
