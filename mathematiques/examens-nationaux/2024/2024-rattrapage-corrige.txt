## Exercice 1

1) $A(2, 0, 1)$, $B(0, 2, 1)$, $C(1, 1, 0)$.
$\vec{AB}\begin{pmatrix} -2 \\ 2 \\ 0 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} -1 \\ 1 \\ -1 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} 2 & 1 \\ 0 & -1 \end{vmatrix}\vec{i} - \begin{vmatrix} -2 & -1 \\ 0 & -1 \end{vmatrix}\vec{j} + \begin{vmatrix} -2 & -1 \\ 2 & 1 \end{vmatrix}\vec{k} = -2\vec{i} - 2\vec{j} + 0\vec{k} \dots$$
Avec le vecteur normal $\vec{n}(1, 1, 2)$ :
$$1(x - 2) + 1(y - 0) + 2(z - 1) = 0 \iff x + y + 2z - 4 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 2x - 2y + 1 = 0 \iff (x - 1)^2 - 1 + (y - 1)^2 - 1 + z^2 + 1 = 0$
$$\iff (x - 1)^2 + (y - 1)^2 + z^2 = 1 = 1^2$$
Le centre est $\Omega(1, 1, 0)$ et le rayon est $R = 1$.

b) Distance de $\Omega$ à $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|1 + 1 + 2(0) - 4|}{\sqrt{1^2 + 1^2 + 2^2}} = \frac{|-2|}{\sqrt{6}} = \frac{2}{\sqrt{6}} = \frac{\sqrt{6}}{3}$$
Comme $d = \sqrt{2/3} \approx 0,816 < R = 1$, le plan $(ABC)$ coupe la sphère $(S)$ selon un cercle $(\Gamma)$.
Le rayon de $(\Gamma)$ est $r = \sqrt{R^2 - d^2} = \sqrt{1 - \frac{2}{3}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$.

## Exercice 2

1) Résolution de $z^2 - 2\sqrt{2}z + 4 = 0$ :
$$\Delta = (-2\sqrt{2})^2 - 4(1)(4) = 8 - 16 = -8 = (2i\sqrt{2})^2$$
Les solutions sont :
$$z_1 = \frac{2\sqrt{2} + 2i\sqrt{2}}{2} = \sqrt{2} + i\sqrt{2} \quad \text{et} \quad z_2 = \sqrt{2} - i\sqrt{2}$$
D'où $S = \{\sqrt{2} - i\sqrt{2}, \sqrt{2} + i\sqrt{2}\}$.

2) a) $a = \sqrt{2} + i\sqrt{2} = 2\left(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right) = 2e^{i\frac{\pi}{4}}$.

b) $a^4 = (2e^{i\frac{\pi}{4}})^4 = 2^4 e^{i\pi} = 16(\cos\pi + i\sin\pi) = -16$.

c) Image de $A$ par la rotation $R(O, \frac{\pi}{2})$ :
$$c = e^{i\frac{\pi}{2}} a = i(\sqrt{2} + i\sqrt{2}) = -\sqrt{2} + i\sqrt{2}$$

## Exercice 3

Nombre total de tirages possibles de 2 boules parmi 9 :
$$\text{Card}(\Omega) = \binom{9}{2} = 36$$

1) - $A$ : « 2 boules de même couleur » (2 rouges, 2 vertes ou 2 blanches) :
$$\text{Card}(A) = \binom{4}{2} + \binom{3}{2} + \binom{2}{2} = 6 + 3 + 1 = 10 \implies p(A) = \frac{10}{36} = \frac{5}{18}$$
- $B$ : « au moins une rouge ». Contraire : « aucune rouge » (2 parmi 5) :
$$\text{Card}(\overline{B}) = \binom{5}{2} = 10 \implies p(B) = 1 - \frac{10}{36} = \frac{26}{36} = \frac{13}{18}$$

2) a) $X \in \{0, 1, 2\}$.
b) Loi de probabilité :
- $p(X = 0) = \frac{\binom{7}{2}}{36} = \frac{21}{36} = \frac{7}{12}$
- $p(X = 1) = \frac{\binom{2}{1}\binom{7}{1}}{36} = \frac{14}{36} = \frac{7}{18}$
- $p(X = 2) = \frac{\binom{2}{2}}{36} = \frac{1}{36}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{21}{36} + 1 \times \frac{14}{36} + 2 \times \frac{1}{36} = \frac{16}{36} = \frac{4}{9}$$

## Exercice 4

1) Par récurrence :
- $u_0 = 1 < 4$, vrai.
- Supposons $u_n < 4$ :
$$u_{n+1} - 4 = \frac{1}{2}u_n + 2 - 4 = \frac{1}{2}(u_n - 4) < 0 \implies u_{n+1} < 4$$
Donc pour tout $n \in \mathbb{N}$, $u_n < 4$.

2) $u_{n+1} - u_n = \frac{1}{2}u_n + 2 - u_n = 2 - \frac{1}{2}u_n = \frac{1}{2}(4 - u_n) > 0$.
La suite est strictement croissante et majorée par 4, donc elle converge.

3) a)
$$v_{n+1} = u_{n+1} - 4 = \frac{1}{2}(u_n - 4) = \frac{1}{2}v_n$$
Donc $(v_n)$ est géométrique de raison $\frac{1}{2}$ et de premier terme $v_0 = u_0 - 4 = -3$.
b) $v_n = -3\left(\frac{1}{2}\right)^n$.
Comme $u_n = v_n + 4$, on a :
$$u_n = 4 - 3\left(\frac{1}{2}\right)^n$$
c) $\lim_{n\to +\infty} u_n = 4$.

## Problème

1) En $0^+$ : $\lim_{x\to 0^+} \frac{\ln x}{x} = -\infty$, donc $\lim_{x\to 0^+} f(x) = \lim_{x\to 0^+} \left(x - 2 - \frac{\ln x}{x}\right) = +\infty$.
L'axe des ordonnées ($x = 0$) est asymptote verticale à $(C_f)$.

2) En $+\infty$ : $\lim_{x\to +\infty} \frac{\ln x}{x} = 0$, donc $\lim_{x\to +\infty} f(x) = +\infty$.
$\lim_{x\to +\infty} [f(x) - (x - 2)] = 0$.
La droite $(D) : y = x - 2$ est asymptote oblique à $(C_f)$ au voisinage de $+\infty$.

3) a) Pour $x > 0$ :
$$f'(x) = 1 - \frac{1 - \ln x}{x^2} = \frac{x^2 - 1 + \ln x}{x^2}$$
b) Pour $x \ge 1$ : $x^2 - 1 \ge 0$ et $\ln x \ge 0 \implies f'(x) \ge 0$.
Pour $0 < x \le 1$ : $x^2 - 1 \le 0$ et $\ln x \le 0 \implies f'(x) \le 0$.
$f'(1) = 0$.
Donc $f$ est décroissante sur $]0, 1]$ et croissante sur $[1, +\infty[$.
Minimum absolu en $x = 1$ : $f(1) = 1 - 2 - 0 = -1$.

4) Position relative : $f(x) - (x - 2) = -\frac{\ln x}{x}$.
- Si $x \in ]0, 1[$ : $\ln x < 0 \implies f(x) - (x - 2) > 0$, donc $(C_f)$ est au-dessus de $(D)$.
- Si $x > 1$ : $\ln x > 0 \implies f(x) - (x - 2) < 0$, donc $(C_f)$ est en dessous de $(D)$.
- En $x = 1$ : $(C_f)$ coupe $(D)$ au point $(1, -1)$.

5) Construction de $(C_f)$ et $(D)$.

6) a) $I = \int_1^e \frac{\ln x}{x} dx = \left[\frac{1}{2}(\ln x)^2\right]_1^e = \frac{1}{2}$.
b) Sur $[1, e]$, $(C_f)$ est en dessous de $(D)$, donc :
$$\mathcal{A} = \int_1^e ((x - 2) - f(x)) dx = I = \frac{1}{2}\text{ cm}^2 = 0,5\text{ cm}^2$$
