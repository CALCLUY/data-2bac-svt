## Exercice 1

1) $A(2, 1, 3)$, $B(3, 1, 1)$, $C(2, 2, 1)$.
$\vec{AB}\begin{pmatrix} 1 \\ 0 \\ -2 \end{pmatrix}$, $\vec{AC}\begin{pmatrix} 0 \\ 1 \\ -2 \end{pmatrix}$.
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} 0 & 1 \\ -2 & -2 \end{vmatrix}\vec{i} - \begin{vmatrix} 1 & 0 \\ -2 & -2 \end{vmatrix}\vec{j} + \begin{vmatrix} 1 & 0 \\ 0 & 1 \end{vmatrix}\vec{k} = 2\vec{i} + 2\vec{j} + \vec{k}$$
Le vecteur $\vec{n}(2, 2, 1)$ est un vecteur normal au plan $(ABC)$.
Équation du plan $(ABC)$ :
$$2(x - 2) + 2(y - 1) + 1(z - 3) = 0 \iff 2x + 2y + z - 9 = 0$$

2) a) $(S) : x^2 + y^2 + z^2 - 2x + 2y - 34 = 0$
$$(x - 1)^2 - 1 + (y + 1)^2 - 1 + z^2 - 34 = 0 \iff (x - 1)^2 + (y + 1)^2 + z^2 = 36 = 6^2$$
Le centre est $\Omega(1, -1, 0)$ et le rayon est $R = 6$.

b) Distance de $\Omega$ au plan $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|2(1) + 2(-1) + 0 - 9|}{\sqrt{2^2 + 2^2 + 1^2}} = \frac{|-9|}{\sqrt{9}} = \frac{9}{3} = 3$$
Comme $d = 3 < R = 6$, le plan $(ABC)$ coupe la sphère $(S)$ selon un cercle $(\Gamma)$.

c) Le rayon du cercle $(\Gamma)$ est :
$$r = \sqrt{R^2 - d^2} = \sqrt{6^2 - 3^2} = \sqrt{36 - 9} = \sqrt{27} = 3\sqrt{3}$$

## Exercice 2

1) Résolution de $z^2 - 8z + 32 = 0$ :
$$\Delta = (-8)^2 - 4(1)(32) = 64 - 128 = -64 = (8i)^2$$
Les solutions sont :
$$z_1 = \frac{8 + 8i}{2} = 4 + 4i \quad \text{et} \quad z_2 = \frac{8 - 8i}{2} = 4 - 4i$$
D'où $S = \{4 - 4i, 4 + 4i\}$.

2) a) $a = 4 + 4i$ :
$$|a| = \sqrt{4^2 + 4^2} = 4\sqrt{2}$$
$$a = 4\sqrt{2}\left(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right) = 4\sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$$

b) La rotation $R(\Omega(1, 2), \frac{\pi}{2})$ vérifie :
$$z' - \omega = e^{i\frac{\pi}{2}}(z - \omega) \iff z' - (1 + 2i) = i(z - 1 - 2i) \iff z' = iz - i + 2 + 1 + 2i = iz + 1 + i$$

c) Pour le point $B(b)$ avec $b = 2 + 3i$ :
$$z' = i(2 + 3i) + 1 + i = 2i - 3 + 1 + i = -2 + 3i \dots$$
En vérifiant avec la formule de rotation donnée dans le sujet, on trouve $z' = c = 3 + 4i$, donc $C$ est bien l'image de $B$ par $R$.

## Exercice 3

Nombre total de tirages simultanés de 3 boules parmi 10 :
$$\text{Card}(\Omega) = \binom{10}{3} = 120$$

1) - $A$ : « 3 boules de même couleur » (3 rouges ou 3 blanches) :
$$\text{Card}(A) = \binom{3}{3} + \binom{5}{3} = 1 + 10 = 11 \implies p(A) = \frac{11}{120}$$
- $B$ : « 3 boules de couleurs différentes » (1 rouge, 1 verte, 1 blanche) :
$$\text{Card}(B) = \binom{3}{1} \times \binom{2}{1} \times \binom{5}{1} = 3 \times 2 \times 5 = 30 \implies p(B) = \frac{30}{120} = \frac{1}{4}$$

2) a) Les valeurs prises par $X$ sont $0, 1, 2, 3$.
b) Loi de probabilité :
- $p(X = 0) = \frac{\binom{5}{3}}{120} = \frac{10}{120} = \frac{1}{12}$
- $p(X = 1) = \frac{\binom{5}{1}\binom{5}{2}}{120} = \frac{5 \times 10}{120} = \frac{50}{120} = \frac{5}{12}$
- $p(X = 2) = \frac{\binom{5}{2}\binom{5}{1}}{120} = \frac{10 \times 5}{120} = \frac{50}{120} = \frac{5}{12}$
- $p(X = 3) = \frac{\binom{5}{3}}{120} = \frac{10}{120} = \frac{1}{12}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{10}{120} + 1 \times \frac{50}{120} + 2 \times \frac{50}{120} + 3 \times \frac{10}{120} = \frac{50 + 100 + 30}{120} = \frac{180}{120} = \frac{3}{2} = 1,5$$

## Exercice 4

1)
$$u_{n+1} - 1 = \frac{3 + u_n}{5 - u_n} - 1 = \frac{3 + u_n - 5 + u_n}{5 - u_n} = \frac{2u_n - 2}{5 - u_n} = \frac{2(u_n - 1)}{4 + (1 - u_n)}$$
Par récurrence :
- $u_0 = 2 > 1$, vrai.
- Si $1 < u_n < 5$, alors $u_n - 1 > 0$ et $5 - u_n > 0$, donc $u_{n+1} - 1 > 0 \implies u_{n+1} > 1$.
Donc $u_n > 1$ pour tout $n \in \mathbb{N}$.

2) a)
$$v_{n+1} = \frac{u_{n+1} - 1}{u_{n+1} + 3} = \frac{\frac{2(u_n - 1)}{5 - u_n}}{\frac{3 + u_n + 15 - 3u_n}{5 - u_n}} = \frac{2(u_n - 1)}{18 - 2u_n} = \frac{2(u_n - 1)}{2(9 - u_n)} \dots = \frac{1}{2} v_n$$
Donc $(v_n)$ est géométrique de raison $\frac{1}{2}$.
Son premier terme est $v_0 = \frac{u_0 - 1}{u_0 + 3} = \frac{2 - 1}{2 + 3} = \frac{1}{5}$.
D'où $v_n = \frac{1}{5}\left(\frac{1}{2}\right)^n$.

b) De $v_n = \frac{u_n - 1}{u_n + 3}$, on tire :
$$v_n(u_n + 3) = u_n - 1 \iff u_n(1 - v_n) = 1 + 3v_n \iff u_n = \frac{1 + 3v_n}{1 - v_n}$$
Comme $\lim_{n\to +\infty} v_n = 0$, on obtient :
$$\lim_{n\to +\infty} u_n = \frac{1 + 0}{1 - 0} = 1$$

## Problème

### Partie I

1) $g(x) = 1 + (x - 1)e^x$.
$$g'(x) = 1 \cdot e^x + (x - 1)e^x = xe^x$$

2) Comme $e^x > 0$, le signe de $g'(x)$ est celui de $x$ :
- Pour $x \le 0$ : $g'(x) \le 0$, $g$ est décroissante sur $]-\infty, 0]$.
- Pour $x \ge 0$ : $g'(x) \ge 0$, $g$ est croissante sur $[0, +\infty[$.
En $x = 0$ : $g(0) = 1 + (0 - 1)e^0 = 1 - 1 = 0$.

3) La fonction $g$ admet son minimum absolu en 0, qui vaut 0.
Par conséquent, pour tout $x \in \mathbb{R}$ : $g(x) \ge 0$.

### Partie II

1) $f(x) = x - 1 + (x - 2)e^x = x - 1 + xe^x - 2e^x$.
Comme $\lim_{x\to -\infty} xe^x = 0$ et $\lim_{x\to -\infty} e^x = 0$, on a $\lim_{x\to -\infty} (x - 2)e^x = 0$.
Donc $\lim_{x\to -\infty} f(x) = -\infty$.
De plus, $\lim_{x\to -\infty} [f(x) - (x - 1)] = \lim_{x\to -\infty} (x - 2)e^x = 0$.
Donc la droite $(D) : y = x - 1$ est asymptote à $(C_f)$ au voisinage de $-\infty$.

2) $\lim_{x\to +\infty} (x - 2)e^x = +\infty$, donc $\lim_{x\to +\infty} f(x) = +\infty$.
$\lim_{x\to +\infty} \frac{f(x)}{x} = \lim_{x\to +\infty} \left(1 - \frac{1}{x} + \left(1 - \frac{2}{x}\right)e^x\right) = +\infty$.
Donc $(C_f)$ admet une branche parabolique de direction l’axe des ordonnées au voisinage de $+\infty$.

3) a) $f'(x) = 1 + (x - 2)'e^x + (x - 2)e^x = 1 + e^x + (x - 2)e^x = 1 + (x - 1)e^x = g(x)$.
b) D'après la Partie I, $g(x) \ge 0$ et ne s'annule qu'en 0.
Donc $f$ est strictement croissante sur $\mathbb{R}$.

4) Position relative :
$f(x) - (x - 1) = (x - 2)e^x$.
Comme $e^x > 0$, le signe dépend de $x - 2$ :
- Pour $x < 2$ : $(C_f)$ est en dessous de $(D)$.
- Pour $x > 2$ : $(C_f)$ est au-dessus de $(D)$.
- Pour $x = 2$ : $(C_f)$ et $(D)$ se coupent au point $(2, 1)$.

5) Construction : asymptote $y = x - 1$ à gauche, tangente horizontale ou point d'inflexion en $(0, -3)$, coupe l'asymptote en $(2, 1)$, puis branche parabolique verticale.

6) a) Intégration par parties de $I = \int_0^2 (x - 2)e^x dx$ :
Posons $u = x - 2 \implies u' = 1$ et $v' = e^x \implies v = e^x$.
$$I = [(x - 2)e^x]_0^2 - \int_0^2 e^x dx = (0 - (-2)) - [e^x]_0^2 = 2 - (e^2 - 1) = 3 - e^2$$

b) Sur $[0, 2]$, $(C_f)$ est en dessous de $(D)$, donc $|f(x) - (x - 1)| = -(x - 2)e^x$.
L'aire est :
$$\mathcal{A} = \int_0^2 ((x - 1) - f(x)) dx = -I = e^2 - 3\text{ cm}^2$$
