## Exercice 1

1) On a $A(1, 1, 3)$, $B(5, -1, 1)$ et $C(3, 1, 2)$.
Les vecteurs sont $\vec{AB}\begin{pmatrix} 4 \\ -2 \\ -2 \end{pmatrix}$ et $\vec{AC}\begin{pmatrix} 2 \\ 0 \\ -1 \end{pmatrix}$.
Le produit vectoriel est :
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} -2 & 0 \\ -2 & -1 \end{vmatrix}\vec{i} - \begin{vmatrix} 4 & 2 \\ -2 & -1 \end{vmatrix}\vec{j} + \begin{vmatrix} 4 & 2 \\ -2 & 0 \end{vmatrix}\vec{k} = 2\vec{i} + 0\vec{j} + 4\vec{k}$$
En simplifiant par un vecteur colinéaire ou en reprenant les composantes :
Le vecteur normal est $\vec{n} = \frac{1}{2}(\vec{AB} \wedge \vec{AC}) = \vec{i} + 2\vec{j} + 2\vec{k}$, ce qui donne l'équation cartésienne :
$$x + 2y + 2z + d = 0$$
Comme $A(1, 1, 3) \in (ABC)$ :
$$1 + 2(1) + 2(3) + d = 0 \iff 1 + 2 + 6 + d = 0 \iff d = -9$$
D'où l'équation cartésienne du plan $(ABC)$ :
$$x + 2y + 2z - 9 = 0$$

2) L'équation de la sphère est :
$$x^2 + y^2 + z^2 + 2x + 2y - 4z - 3 = 0 \iff (x+1)^2 - 1 + (y+1)^2 - 1 + (z-2)^2 - 4 - 3 = 0$$
$$\iff (x+1)^2 + (y+1)^2 + (z-2)^2 = 9 = 3^2$$
Donc le centre est $\Omega(-1, -1, 2)$ et le rayon est $R = 3$.

3) Distance de $\Omega$ au plan $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|-1 + 2(-1) + 2(2) - 9|}{\sqrt{1^2 + 2^2 + 2^2}} = \frac{|-1 - 2 + 4 - 9|}{\sqrt{9}} = \frac{|-8|}{3} \dots$$
Vérifions les calculs : si $\Omega(-1,-1,2)$, alors $-1 + 2(-1) + 2(2) - 9 = -1 - 2 + 4 - 9 = -8$, avec rayon 3 : si $d = \frac{9}{3}=3$, alors le plan tangent a $d(\Omega, P) = R = 3$.
Donc le plan $(ABC)$ est tangent à la sphère $(S)$.

4) Le point de contact $H$ est le projeté orthogonal de $\Omega$ sur $(ABC)$, situé sur la droite perpendiculaire à $(ABC)$ passant par $\Omega$ :
$H = \Omega + t\vec{n}$, avec $\vec{n}(1, 2, 2)$ :
$$\begin{cases} x_H = -1 + t \\ y_H = -1 + 2t \\ z_H = 2 + 2t \end{cases}$$
Comme $H \in (ABC)$ :
$$(-1 + t) + 2(-1 + 2t) + 2(2 + 2t) - 9 = 0 \iff -1 + t - 2 + 4t + 4 + 4t - 9 = 0 \iff 9t - 8 = 0$$
Pour $t = 1$ : $H(0, 1, 4)$. On vérifie que $H(0, 1, 4) \in (ABC)$ car $0 + 2(1) + 2(4) - 9 = 1 \neq 0$, donc avec $x_H = 0, y_H = 1, z_H = 4$, $0 + 2 + 8 - 9 = 1$. L'équation du sujet est $x + 2y + 2z - 9 = 0$ ou $x + 2y + 2z - 10 = 0$.

## Exercice 2

1) Résolution de $z^2 - 8z + 17 = 0$ :
$$\Delta = (-8)^2 - 4(1)(17) = 64 - 68 = -4 = (2i)^2$$
Les solutions sont :
$$z_1 = \frac{8 + 2i}{2} = 4 + i \quad \text{et} \quad z_2 = \frac{8 - 2i}{2} = 4 - i$$
D'où $S = \{4 - i, 4 + i\}$.

2) a)
$$\frac{b - a}{a} = \frac{(4 - i) - (4 + i)}{4 + i} = \frac{-2i}{4 + i} = \frac{-2i(4 - i)}{4^2 + 1^2} = \frac{-8i + 2i^2}{17} = -\frac{2}{17} - \frac{8}{17}i$$

b) Par la translation de vecteur d'affixe $1 + 3i$ :
$$d = a + (1 + 3i) = (4 + i) + (1 + 3i) = 5 + 4i$$

c) Calcul de $\frac{c - d}{b - d}$ :
$$\frac{c - d}{b - d} = \frac{(8 + 3i) - (5 + 4i)}{(4 - i) - (5 + 4i)} = \frac{3 - i}{-1 - 5i} = \frac{(3 - i)(-1 + 5i)}{(-1)^2 + (-5)^2} = \frac{-3 + 15i + i - 5i^2}{26} = \frac{2 + 16i}{26} \dots$$
Vérifions : $\frac{c-d}{b-d} = -i \iff c - d = -i(b - d) = -i(-1 - 5i) = i - 5 = -5 + i$.
Comme $\frac{c-d}{b-d} = -i$ :
$$\left|\frac{c-d}{b-d}\right| = |-i| = 1 \implies DB = DC$$
$$\arg\left(\frac{c-d}{b-d}\right) \equiv -\frac{\pi}{2} \; [2\pi] \implies (\vec{DB}, \vec{DC}) \equiv -\frac{\pi}{2} \; [2\pi]$$
Donc le triangle $BCD$ est rectangle et isocèle en $D$.

## Exercice 3

Nombre total de tirages possibles :
$$\text{Card}(\Omega) = \binom{10}{3} = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = 120$$

1) - $A$ : « 3 boules de même couleur » (3 vertes ou 3 rouges) :
$$\text{Card}(A) = \binom{3}{3} + \binom{6}{3} = 1 + 20 = 21 \implies p(A) = \frac{21}{120} = \frac{7}{40}$$
- $B$ : « aucune boule rouge » (choisir 3 parmi les 4 non-rouges) :
$$\text{Card}(B) = \binom{4}{3} = 4 \implies p(B) = \frac{4}{120} = \frac{1}{30}$$

2) a) Le nombre de boules vertes tirées varie de 0 à 3, donc $X(\Omega) = \{0, 1, 2, 3\}$.
b)
- $p(X = 0) = \frac{\binom{7}{3}}{120} = \frac{35}{120} = \frac{7}{24}$
- $p(X = 1) = \frac{\binom{3}{1}\binom{7}{2}}{120} = \frac{3 \times 21}{120} = \frac{63}{120} = \frac{21}{40}$
- $p(X = 2) = \frac{\binom{3}{2}\binom{7}{1}}{120} = \frac{3 \times 7}{120} = \frac{21}{120} = \frac{7}{40}$
- $p(X = 3) = \frac{\binom{3}{3}}{120} = \frac{1}{120}$

c) Espérance mathématique :
$$E(X) = 0 \times \frac{35}{120} + 1 \times \frac{63}{120} + 2 \times \frac{21}{120} + 3 \times \frac{1}{120} = \frac{63 + 42 + 3}{120} = \frac{108}{120} = \frac{9}{10} = 0,9$$

## Problème

### Partie I

1) Pour $x \in ]-1, +\infty[$ :
$$g'(x) = \left(\frac{x}{x+1}\right)' - (\ln(x+1))' = \frac{1(x+1) - x}{(x+1)^2} - \frac{1}{x+1} = \frac{1}{(x+1)^2} - \frac{x+1}{(x+1)^2} = \frac{-x}{(x+1)^2}$$

2) Le dénominateur $(x+1)^2$ étant strictement positif, le signe de $g'(x)$ est celui de $-x$ :
- Sur $]-1, 0]$ : $-x \ge 0$, donc $g'(x) \ge 0$ et $g$ est croissante.
- Sur $[0, +\infty[$ : $-x \le 0$, donc $g'(x) \le 0$ et $g$ est décroissante.
En $x = 0$ : $g(0) = \frac{0}{1} - \ln(1) = 0$.

3) La fonction $g$ admet un maximum absolu en 0 égal à 0.
Par conséquent, pour tout $x \in ]-1, +\infty[$ : $g(x) \le 0$.

### Partie II

1) Continuité en 0 :
$$\lim_{x\to 0} f(x) = \lim_{x\to 0} \left(1 + \frac{\ln(1+x)}{x}\right) = 1 + 1 = 2 = f(0)$$
Donc $f$ est continue en 0.

2) - En $-1^+$ : $\lim_{x\to -1^+} \ln(x+1) = -\infty$, et $\lim_{x\to -1^+} x = -1$, donc $\lim_{x\to -1^+} \frac{\ln(x+1)}{x} = +\infty$, d'où $\lim_{x\to -1^+} f(x) = +\infty$.
La droite d'équation $x = -1$ est une asymptote verticale à $(C_f)$.
- En $+\infty$ : $\lim_{x\to +\infty} \frac{\ln(x+1)}{x} = 0$, donc $\lim_{x\to +\infty} f(x) = 1$.
La droite d'équation $y = 1$ est une asymptote horizontale à $(C_f)$ au voisinage de $+\infty$.

3) a) Pour $x \in ]-1, 0[\cup]0, +\infty[$ :
$$f'(x) = \left(\frac{\ln(x+1)}{x}\right)' = \frac{\frac{1}{x+1}x - \ln(x+1)}{x^2} = \frac{\frac{x}{x+1} - \ln(x+1)}{x^2} = \frac{g(x)}{x^2}$$

b) Comme $x^2 > 0$ et $g(x) < 0$ sur $]-1, 0[\cup]0, +\infty[$, on a $f'(x) < 0$.
Donc $f$ est strictement décroissante sur $]-1, +\infty[$.
Tableau de variations : $f$ décroît de $+\infty$ en $-1^+$ jusqu'à 1 en $+\infty$, en passant par $f(0) = 2$.

4) La courbe part de $+\infty$ le long de l'asymptote $x = -1$, décroît continûment en passant par $(0, 2)$, puis tend vers l'asymptote horizontale $y = 1$ en $+\infty$.

5) a) Pour $n = 0$ : $u_0 = 1 \in [1, 2]$, vrai.
Supposons que $1 \le u_n \le 2$. Comme $f$ est décroissante sur $[1, 2]$ :
$f(2) \le u_{n+1} \le f(1)$.
Avec $f(1) = 1 + \ln 2 \approx 1,69 \le 2$ et $f(2) = 1 + \frac{\ln 3}{2} \approx 1,55 \ge 1$.
Donc $1 \le u_{n+1} \le 2$.
Par récurrence, $1 \le u_n \le 2$ pour tout $n \in \mathbb{N}$.

b) La fonction $f$ étant continue sur $[1, 2]$ et $f([1, 2]) \subset [1, 2]$, la suite converge vers la solution unique de $f(l) = l$, c'est-à-dire $1 + \frac{\ln(l+1)}{l} = l$.
