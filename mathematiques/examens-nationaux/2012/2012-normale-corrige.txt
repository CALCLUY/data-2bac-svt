## Exercice 1

1) On a $A(0, 3, 1)$, $B(-1, 3, 0)$ et $C(0, 5, 0)$.
Les vecteurs sont $\vec{AB}\begin{pmatrix} -1 \\ 0 \\ -1 \end{pmatrix}$ et $\vec{AC}\begin{pmatrix} 0 \\ 2 \\ -1 \end{pmatrix}$.
Le produit vectoriel est :
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} 0 & 2 \\ -1 & -1 \end{vmatrix}\vec{i} - \begin{vmatrix} -1 & 0 \\ -1 & -1 \end{vmatrix}\vec{j} + \begin{vmatrix} -1 & 0 \\ 0 & 2 \end{vmatrix}\vec{k} = 2\vec{i} - \vec{j} - 2\vec{k}$$
Le plan $(ABC)$ passe par $A(0, 3, 1)$ et admet $\vec{n}(2, -1, -2)$ comme vecteur normal, d'où :
$$2(x - 0) - 1(y - 3) - 2(z - 1) = 0 \iff 2x - y + 3 - 2z + 2 = 0 \iff 2x - y - 2z + 5 = 0$$

2) a) L'équation de la sphère $(S)$ est :
$$x^2 + y^2 + z^2 - 4x - 4y - 4z - 1 = 0 \iff (x - 2)^2 - 4 + (y - 2)^2 - 4 + (z - 2)^2 - 4 - 1 = 0$$
$$\iff (x - 2)^2 + (y - 2)^2 + (z - 2)^2 = 9 = 3^2$$
Donc le centre est $\Omega(2, 2, 2)$ et le rayon est $R = 3$.

b) Distance du point $\Omega$ au plan $(ABC)$ :
$$d(\Omega, (ABC)) = \frac{|2(2) - 2 - 2(2) + 5|}{\sqrt{2^2 + (-1)^2 + (-2)^2}} = \frac{|4 - 2 - 4 + 5|}{\sqrt{4 + 1 + 4}} = \frac{3}{3} = 1$$
Comme $d(\Omega, (ABC)) = 1 < R = 3$, le plan $(ABC)$ coupe la sphère $(S)$ suivant un cercle $(\Gamma)$.

c) Le centre $H$ du cercle $(\Gamma)$ est le projeté orthogonal de $\Omega$ sur le plan $(ABC)$ :
$H = \Omega + t\vec{n}$, donc :
$$\begin{cases} x = 2 + 2t \\ y = 2 - t \\ z = 2 - 2t \end{cases}$$
Comme $H \in (ABC)$ :
$$2(2 + 2t) - (2 - t) - 2(2 - 2t) + 5 = 0 \iff 4 + 4t - 2 + t - 4 + 4t + 5 = 0 \iff 9t + 3 = 0 \iff t = -\frac{1}{3}$$
D'où les coordonnées de $H$ :
$$x_H = 2 + 2\left(-\frac{1}{3}\right) = \frac{4}{3}, \quad y_H = 2 - \left(-\frac{1}{3}\right) = \frac{7}{3}, \quad z_H = 2 - 2\left(-\frac{1}{3}\right) = \frac{8}{3}$$
Soit $H\left(\frac{4}{3}, \frac{7}{3}, \frac{8}{3}\right)$.
Le rayon du cercle $(\Gamma)$ est :
$$r = \sqrt{R^2 - d^2} = \sqrt{3^2 - 1^2} = \sqrt{8} = 2\sqrt{2}$$

## Exercice 2

1) Résolution de $z^2 - 12z + 61 = 0$ :
$$\Delta = (-12)^2 - 4(1)(61) = 144 - 244 = -100 = (10i)^2$$
Les solutions sont :
$$z_1 = \frac{12 + 10i}{2} = 6 + 5i \quad \text{et} \quad z_2 = \frac{12 - 10i}{2} = 6 - 5i$$
D'où $S = \{6 - 5i, 6 + 5i\}$.

2) a) On calcule :
$$\frac{a - c}{b - c} = \frac{(6 - 5i) - (2 + i)}{(4 - 2i) - (2 + i)} = \frac{4 - 6i}{2 - 3i} = \frac{2(2 - 3i)}{2 - 3i} = 2 \in \mathbb{R}$$
Puisque le rapport est un réel, les vecteurs $\vec{CB}$ et $\vec{CA}$ sont colinéaires, d'où les points $A, B$ et $C$ sont alignés.

3) a) Le centre de la rotation est le point invariant :
$$\omega = -i\omega - 1 + 5i \iff \omega(1 + i) = -1 + 5i \iff \omega = \frac{-1 + 5i}{1 + i} = \frac{(-1 + 5i)(1 - i)}{2} = \frac{-1 + i + 5i + 5}{2} = \frac{4 + 6i}{2} = 2 + 3i$$

b) Image de $C(c)$ par $R$ avec $c = 2 + i$ :
$$c' = -i(2 + i) - 1 + 5i = -2i + 1 - 1 + 5i = 3i$$

## Exercice 3

1) Par récurrence :
- Pour $n = 0$ : $u_0 = 13 < 14$, vrai.
- Hérédité : Supposons $u_n < 14$.
$$u_{n+1} - 14 = \frac{1}{2}u_n + 7 - 14 = \frac{1}{2}u_n - 7 = \frac{1}{2}(u_n - 14) < 0$$
Donc $u_{n+1} < 14$.
- Conclusion : Pour tout $n \in \mathbb{N}$, $u_n < 14$.

2) a) Pour tout $n \in \mathbb{N}$ :
$$v_{n+1} = 14 - u_{n+1} = 14 - \left(\frac{1}{2}u_n + 7\right) = 7 - \frac{1}{2}u_n = \frac{1}{2}(14 - u_n) = \frac{1}{2}v_n$$
Donc $(v_n)$ est une suite géométrique de raison $q = \frac{1}{2}$.
Son premier terme est $v_0 = 14 - u_0 = 14 - 13 = 1$.
D'où pour tout $n \in \mathbb{N}$ :
$$v_n = \left(\frac{1}{2}\right)^n$$

b) De $v_n = 14 - u_n$, on tire :
$$u_n = 14 - v_n = 14 - \left(\frac{1}{2}\right)^n$$
Comme $|1/2| < 1$, on a $\lim_{n\to +\infty} \left(\frac{1}{2}\right)^n = 0$, donc $\lim_{n\to +\infty} u_n = 14$.

c) On cherche le plus petit entier $n$ tel que :
$$u_n > 13,99 \iff 14 - \left(\frac{1}{2}\right)^n > 13,99 \iff \left(\frac{1}{2}\right)^n < 0,01 \iff 2^n > 100$$
Comme $2^6 = 64$ et $2^7 = 128 > 100$, le plus petit entier naturel est $n = 7$.

## Problème

### Partie I

1) Pour tout $x \in ]0, +\infty[$ :
$$g'(x) = (x^2 - 1)' + 2(x^2\ln x)' = 2x + 2\left(2x\ln x + x^2 \times \frac{1}{x}\right) = 2x + 4x\ln x + 2x = 4x\ln x + 4x = 4x(\ln x + 1)$$

2) $g(1) = 1^2 - 1 + 2(1^2)\ln 1 = 0$.
Signe de $g(x)$ :
Comme $g'(x) = 4x(\ln x + 1)$, $g'(x) = 0 \iff \ln x = -1 \iff x = e^{-1}$.
Sur $]0, 1]$, la fonction s'annule en 1 et $g(x) \le 0$ pour tout $x \in ]0, 1]$.
Sur $[1, +\infty[$, $g(x) \ge 0$ pour tout $x \in [1, +\infty[$.

### Partie II

1) $\lim_{x\to 0^+} (x^2 - 1) = -1$ et $\lim_{x\to 0^+} \ln x = -\infty$.
Donc $\lim_{x\to 0^+} f(x) = (-1)(-\infty) = +\infty$.
La droite d'équation $x = 0$ (axe des ordonnées) est asymptote verticale à $(C_f)$.

2) $\lim_{x\to +\infty} (x^2 - 1) = +\infty$ et $\lim_{x\to +\infty} \ln x = +\infty$, donc $\lim_{x\to +\infty} f(x) = +\infty$.
Calcul de la branche infinie :
$$\frac{f(x)}{x} = \frac{x^2 - 1}{x}\ln x = \left(x - \frac{1}{x}\right)\ln x$$
Comme $\lim_{x\to +\infty} (x - 1/x) = +\infty$ et $\lim_{x\to +\infty} \ln x = +\infty$, on a $\lim_{x\to +\infty} \frac{f(x)}{x} = +\infty$.
La courbe $(C_f)$ admet une branche parabolique de direction l’axe des ordonnées au voisinage de $+\infty$.

3) a) Pour $x \in ]0, +\infty[$ :
$$f'(x) = (x^2 - 1)'\ln x + (x^2 - 1)(\ln x)' = 2x\ln x + \frac{x^2 - 1}{x} = \frac{2x^2\ln x + x^2 - 1}{x} = \frac{g(x)}{x}$$

b) Comme $x > 0$, le signe de $f'(x)$ est celui de $g(x)$ :
- Pour $x \in ]0, 1]$ : $f'(x) \le 0$, donc $f$ est décroissante sur $]0, 1]$.
- Pour $x \in [1, +\infty[$ : $f'(x) \ge 0$, donc $f$ est croissante sur $[1, +\infty[$.
$f(1) = 0$ est la valeur minimale absolue de $f$ sur $]0, +\infty[$.

4) Position relative de $(C_f)$ par rapport à l'axe des abscisses :
$f(x) = (x^2 - 1)\ln x$.
- Pour $x \in ]0, 1[$ : $x^2 - 1 < 0$ et $\ln x < 0 \implies f(x) > 0$.
- Pour $x > 1$ : $x^2 - 1 > 0$ et $\ln x > 0 \implies f(x) > 0$.
- Pour $x = 1$ : $f(1) = 0$.
Donc pour tout $x \in ]0, +\infty[$, $(C_f)$ est située au-dessus de l'axe des abscisses et le touche au point $(1, 0)$.

5) Tracé de $(C_f)$ : elle descend de $+\infty$ le long de l'axe vertical, atteint son minimum en $(1, 0)$ avec une tangente horizontale, puis remonte vers $+\infty$ avec une branche parabolique verticale.

6) a) Intégration par parties de $\int_1^2 x\ln x dx$ :
Posons $u(x) = \ln x \implies u'(x) = \frac{1}{x}$, et $v'(x) = x \implies v(x) = \frac{x^2}{2}$.
$$\int_1^2 x\ln x dx = \left[\frac{x^2}{2}\ln x\right]_1^2 - \int_1^2 \frac{x^2}{2} \times \frac{1}{x} dx = 2\ln 2 - \left[\frac{x^2}{4}\right]_1^2 = 2\ln 2 - \left(1 - \frac{1}{4}\right) = 2\ln 2 - \frac{3}{4}$$

b) On a $f(x) = x^2\ln x - \ln x$. En intégrant par parties $\int_1^2 x^2\ln x dx$ :
Posons $u = \ln x \implies u' = 1/x$, $v' = x^2 \implies v = x^3/3$.
$$\int_1^2 x^2\ln x dx = \left[\frac{x^3}{3}\ln x\right]_1^2 - \int_1^2 \frac{x^2}{3} dx = \frac{8}{3}\ln 2 - \left[\frac{x^3}{9}\right]_1^2 = \frac{8}{3}\ln 2 - \frac{7}{9}$$
De plus, $\int_1^2 \ln x dx = [x\ln x - x]_1^2 = 2\ln 2 - 1$.
D'où :
$$\int_1^2 f(x) dx = \left(\frac{8}{3}\ln 2 - \frac{7}{9}\right) - (2\ln 2 - 1) = \frac{2}{3}\ln 2 + \frac{2}{9}$$

c) L'aire demandée est :
$$\mathcal{A} = \int_1^2 f(x) dx \times (2\text{ cm} \times 2\text{ cm}) = 4\left(\frac{2}{3}\ln 2 + \frac{2}{9}\right)\text{ cm}^2 = \left(\frac{8}{3}\ln 2 + \frac{8}{9}\right)\text{ cm}^2$$
